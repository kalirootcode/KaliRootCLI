## 🧠 El Motor DOMINION 3.0

A diferencia de las IAs comerciales que censuran, limitan y evitan temas técnicos, **DOMINION 3.0** fue entrenado con un enfoque diferente:

> **"Ético pero sin filtros innecesarios."**

### ¿Qué significa esto?

✅ **Respuestas técnicas completas** — No te dirá *"No puedo ayudarte con eso"* cuando preguntes sobre técnicas de pentesting legítimas.

✅ **Contexto de seguridad ofensiva** — Entiende la diferencia entre un estudiante aprendiendo y un atacante malicioso. Está diseñado para **educación y profesionalismo**.

✅ **Límites inteligentes** — Tiene restricciones éticas calibradas: no generará malware destructivo, no facilitará ataques ilegales, pero **sí te explicará cómo funcionan** para que puedas defenderte mejor.

✅ **Memoria persistente** — Recuerda tus conversaciones anteriores y el contexto de tu proyecto actual.

✅ **Conexión a Internet en tiempo real** — Busca CVEs actualizados, exploits recientes y documentación técnica sin que salgas de tu terminal.

## 🚀 Instalación Rápida

```bash
# Desde PyPI (Universal)
pip install kr-cli-dominion

# Ejecutar
kr-cli
```

Compatible con **Kali Linux**, **Parrot OS**, **Ubuntu**, **Debian**, **Arch** y **Termux (Android)**.

> 💡 **Tip:** En Termux, ejecuta primero: `pkg install python clang cmake rust`
