## 🚀 Instalación

Instalación directa desde PyPI. Compatible con **Kali Linux**, **Parrot OS**, **Ubuntu** y **Termux**.

```bash
# Instalación universal
pip install kr-cli-dominion

# Ejecutar
kr-cli
```

> **Nota para usuarios de Termux:** Si encuentras errores de compilación, asegúrate de instalar las dependencias base: `pkg install python libxml2 libxslt clang cmake rust build-essential`
